# Registro Emocional Web

## Descripción

Proyecto colaborativo del Tecno-LAB i33 de la Escuela Integral Artística i33.

La aplicación permite registrar emociones de forma sencilla desde el navegador. Está pensada como práctica educativa para estudiantes que están comenzando a aprender desarrollo web.

## Objetivo

Registrar emociones, intensidad, fecha y una observación breve. También permite visualizar un historial y estadísticas simples.

## Tecnologías

- HTML5
- CSS3
- JavaScript Vanilla

## Cómo ejecutar

Abrí el archivo `index.html` en un navegador web.

También se puede usar la extensión Live Server de Visual Studio Code para ver el proyecto localmente mientras se trabaja.

## Persistencia

Los registros se guardan con `localStorage` como recurso educativo para aprender persistencia en el navegador.

`localStorage` no debe considerarse una base de datos institucional ni un lugar seguro para guardar información personal sensible.
